## 무엇이었나
티켓 1장 = 문서 1개(user_tickets)인 지금 구조를 「같은 조건의 티켓 여러 장 = 문서 1개(count)」로 바꾸려던 작업입니다.
- user_tickets 문서에 `count`(없으면 1), ticket_transactions 문서에 `qty`(없으면 1)를 둡니다.
- 쓸 때는 받은 날 오래된 순으로 차감합니다. 묶음 일부만 쓰면 count 를 줄이고, 쓴 만큼을 used 문서로 따로 남깁니다.
- 앱(app/index.html)은 적립·차감·장수 표시까지 거의 다 바꿨습니다. CMS(cms/index.html)는 대시보드 합계와 회원 장수 일부까지 바꿨습니다.
- demo-accounts, scenario, scripts/seed-demo.js, 기존 데이터 이관(합치기)은 손대지 않았습니다.
