# 데모와 STG가 달라진 지점

데모에서 기획을 다듬으며 STG와 달라진 지점을 기록한다. 개발 요청 여부는 김반장이 정한다.

STG 상태는 실제 CMS 소스(`inetkr/pricepick-cms` staging 브랜치)에서 확인한 것만 적는다. 확인 시점의 커밋을 함께 적는다.
