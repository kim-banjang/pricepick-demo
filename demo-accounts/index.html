데모 계정 관리
데모에서 앱을 테스트할 때 가상 데이터를 어느 계정에 넣을지 여기서 확인합니다.
쓰는 법 — 계정 하나가 한 줄입니다. 테스트 기기가 여러 대면 같은 이름으로 줄을 여러 개 넣으세요 — 이름이 같으면 자동으로 묶여 이름 칸이 하나로 합쳐집니다. 계정 ID는 앱 마이 화면 상단의 ID 「복사」 단추로 얻습니다. 여기 적힌 ID 칩을 누르면 전체 ID가 복사됩니다.
닉네임은 앱이 지어 준 이름(예: 꼼꼼한햄스터94)이거나 알아보시려고 적는 구분용 이름(예: 아이폰15 테스트)입니다. 표시일 뿐이고 비워 둬도 됩니다 — 실제로 쓰는 값은 계정 ID입니다.
저장이 막혀 있습니다. Firestore 규칙에 demo_accounts 공개 규칙이 아직 게시되지 않았습니다. 저장소의 firestore.rules에 규칙은 들어가 있으니, Firebase 콘솔 → Firestore Database → 규칙에서 한 번 게시하면 바로 열립니다.
